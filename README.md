# a01073229158-ai-programming-week11

## 데이터

- **출처:** 12주차 실습에서 제공된 `scores_2026.csv`와 손계산 검증용 `mini.csv`입니다. 외부 데이터를 결합하지 않았습니다.
- **행 수:** `scores_2026.csv`는 헤더를 제외하고 114행, `mini.csv`는 10행입니다.
- **열 설명:** `학번`은 학생 식별 번호(문자), `이름`은 학생 이름(문자), `반`은 반 이름(문자), `과목`은 과목명(문자), `점수`는 0~100 정수 점수입니다.
- **빈 칸 처리:** 점수가 비어 있는 행은 분석에서 제외합니다. 결측 점수는 실제 성적을 알 수 없으므로 0이나 평균으로 임의 대체하지 않습니다. 임의로 채우면 실제 관측값처럼 합계와 평균에 반영되어 결과를 왜곡할 수 있습니다.
